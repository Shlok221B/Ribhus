# Company research

India company-research skill for Ribhus. Install with:

```bash
ribhus skill install company-research
```

## What it does

Produce a sourced brief about an Indian company using only legally accessible public information (web, news, MCA public pages).

Hero prompt:

> Research this Indian company: Zoho

## Package layout

- `config.yaml` — name, version, triggers, permissions
- `skill.md` — workflow the agent must follow
- `examples.md` — sample prompts
- `tools.py` — notes only (not auto-imported)
- `tests/` — package checks

See [docs/skills.md](../../docs/skills.md) for the contributor guide.
